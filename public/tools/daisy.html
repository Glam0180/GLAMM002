/// cómo usar — daisy
— ✕

composición de flores controlada con el mouse y el scroll.

  1. mueve el mouse sobre el lienzo para animar el fondo base
  2. haz scroll con la ruedita para revelar el fondo alterno y las flores
  3. mientras más scrolleas, más flores aparecen encima
  4. al dejar de scrollear, vuelve solo al fondo base
  5. si no hay movimiento, la escena queda quieta
