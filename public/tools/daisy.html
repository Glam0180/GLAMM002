/// cómo usar — daisy
— ✕

composición de flores controlada con gestos de tu mano frente a la cámara.

  1. activa "activar cámara" en el panel derecho
  2. mueve la mano para animar el fondo base
  3. cierra el pinch (pulgar + índice) para revelar el fondo alterno
  4. sigue cerrando el pinch para hacer crecer las flores
  5. abre la mano para volver al estado inicial
