/// cómo usar — holocloth
— ✕

una tela holográfica con física real: agárrala, arrúgala y mira cómo el foil cambia de color con la luz.

  1. agarra la tela y arrástrala; mantén la rueda del mouse para arrugarla hacia ese punto
  2. arrastra el fondo para girar la cámara, rueda para zoom
  3. cambia el preset, el acabado y el brillo holográfico
  4. sube tu imagen como tela o pon gráficos encima
  5. exporta png o graba video
