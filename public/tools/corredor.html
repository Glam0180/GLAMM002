/// cómo usar — corredor tipográfico
— ✕

un pasillo 3d abierto al cielo: pared izquierda, suelo y pared derecha llevan texto que corre hacia el punto de fuga y se pierde en la niebla. loop exacto.

  1. escribe el texto de cada superficie: pared izquierda, suelo y pared derecha
  2. elige tipografía, punto de fuga, rotación y perspectiva
  3. mantén presionado el lienzo para acelerar poco a poco
  4. ajusta colores, cielo, niebla, el carro y cuántas palabras avanza el loop
  5. exporta el loop mp4 exacto o un png
